# BUZZ — онлайн игра-баззер

Лобби, ведущий, кнопка «кто первый», ответы и очки. Всё в реальном времени через WebSocket.

## Что где

```
buzz/
├── server.js          # сервер (Node.js + WebSocket)
├── package.json
└── public/
    └── index.html     # клиент (весь фронтенд в одном файле)
```

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Открой `http://localhost:3000`.

Чтобы друзья в той же Wi-Fi сети подключились — узнай свой локальный IP
(`ipconfig` на Windows / `ifconfig` на Mac-Linux) и дай им ссылку вида
`http://192.168.1.50:3000`.

## Как играть

1. Все вводят ник на главной.
2. Один жмёт **Создать лобби** — он становится ведущим (♛).
3. Остальные видят лобби в списке и жмут **Войти**. Либо заходят по коду / по ссылке
   (ведущий может нажать на чип с кодом вверху — скопируется прямая ссылка).
4. Ведущий жмёт **Начать игру**.
5. Ведущий жмёт **Начать голосование** → у игроков загорается большая кнопка.
6. Кто первым нажал — у него появляется поле ввода, у остальных кнопка гаснет.
   Первенство определяет сервер, так что одновременное нажатие невозможно.
7. Игрок пишет ответ и отправляет. Ведущий видит текст и жмёт
   **Апрув** (+1 балл) или **Денай** (без балла). Раунд сбрасывается.
8. Лидер по очкам переливается градиентом в таблице слева.

Кнопка **Новый раунд** у ведущего — аварийный сброс, если раунд завис
(например, игрок ушёл, не ответив).

# Как поставить на сервер

## Вариант 1 — VPS (свой сервер, полный контроль)

Подойдёт любой VPS с Ubuntu.

```bash
# 1. Установить Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. Закинуть проект на сервер (с локальной машины)
scp -r buzz/ user@ТВОЙ_IP:/var/www/buzz

# 3. На сервере: установить зависимости
cd /var/www/buzz
npm install --production

# 4. Запустить под менеджером процессов, чтобы не падало
sudo npm install -g pm2
pm2 start server.js --name buzz
pm2 save
pm2 startup          # выполни команду, которую он выведет
```

Игра уже доступна на `http://ТВОЙ_IP:3000`.

### Домен и HTTPS через nginx

Важно: в конфиге обязательны заголовки `Upgrade`/`Connection`, иначе WebSocket не пройдёт.

```nginx
server {
    listen 80;
    server_name твой-домен.ru;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }
}
```

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d твой-домен.ru
```

Клиент сам переключится на `wss://`, когда сайт откроется по HTTPS — ничего править не нужно.

## Вариант 2 — хостинг с готовым деплоем (проще всего)

**Render / Railway / Fly.io** — все поддерживают WebSocket из коробки и умеют
деплоить прямо из GitHub.

Например, на Render:
1. Залей папку в репозиторий GitHub.
2. New → Web Service → выбери репозиторий.
3. Build command: `npm install`
4. Start command: `npm start`
5. Готово. Порт сервер берёт из `process.env.PORT` — уже настроено.

> ⚠️ Vercel и Netlify **не подойдут** — они не держат постоянные WebSocket-соединения.

## Вариант 3 — быстро показать друзьям прямо со своего компьютера

```bash
npm start
npx localtunnel --port 3000
```

Даст публичную ссылку. Удобно для теста, но канал медленный — для постоянной игры бери VPS.

## Технические заметки

- **Состояние хранится в памяти.** Перезапуск сервера = все лобби пропадают.
  Для игры с друзьями это нормально. Если нужна устойчивость — состояние легко
  переложить в Redis.
- **Защита от одновременного нажатия** сделана на сервере: Node обрабатывает
  входящие сообщения по одному, поэтому первый дошедший пакет занимает слот,
  а все остальные видят, что `buzzedBy` уже занят, и отбрасываются.
- **Ведущий вышел → лобби закрывается** и всех выкидывает в меню.
- Автопереподключение при обрыве связи встроено (индикатор «СВЯЗЬ» вверху справа).
